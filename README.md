# Movie Recommendation System 🎬

An AI-powered movie recommendation system built using Python, Machine Learning, and FastAPI.  
The system uses content-based filtering to recommend similar movies and integrates with the TMDB API to fetch movie posters and ratings.

## Features

- 🎯 Content-based movie recommendations
- 🤖 Machine learning model using TF-IDF and cosine similarity
- ⚡ FastAPI backend for serving recommendations
- 🖼️ TMDB API integration for movie posters and ratings
- 📄 Interactive API documentation using Swagger UI

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- FastAPI
- TMDB API
- Uvicorn
